Overview

LillePchat combines a website, a map and an AI-powered conversation. It provides one place to keep track of visits to favourite venues and to ask Peter.

  • Venue mapGoogle Maps presents favourite venues geographically.
  • Visit managementVisits can be planned and kept organised.
  • Ask PeterA conversational interface provides a direct way to ask Peter.
  • Connected dataGoogle Drive and Python support the project behind the interface.
