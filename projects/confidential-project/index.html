Overview

This confidential project combines a website, a map and an AI-powered conversation. It provides one place to keep track of visits to favourite venues and to ask a friend.

  • Venue mapGoogle Maps presents favourite venues geographically.
  • Visit managementVisits can be planned and kept organised.
  • Ask a friendA conversational interface provides a direct way to ask a friend.
  • Connected dataGoogle Drive and Python support the project behind the interface.
